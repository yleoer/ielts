# 词间更新记录

每个桌面端 PR 就是一次发布：在 PR 里升版本号，并在最上面加一节 `## <版本号>`。合并到 master 后，这一节就是 GitHub Release 与程序内“新版说明”的正文。说明写给使用者，按纯文本列表书写，不用加粗或标题。0.6.0 及更早的版本见 [GitHub Releases](https://github.com/yleoer/ielts/releases)。

## 0.7.1

- 切题不再跳动：答完后当前题留在原处，下一题到了直接替换，输入框不会先消失再出现，焦点也不会丢。
- 练习页释义区固定预留两条次要释义的高度，前后两题释义条数不同时，输入框位置不变。

## 0.7.0

- 听读音再拼一次：练习页输入框右侧新增喇叭按钮（需已导入含读音的资源包）。作答前点一下，本题计为“忘记”并保存，但不显示答案，可凭读音再拼一次；拼对直接进入下一题，拼错或留空才显示答案订正，这次重拼不另外计分。中文释义不再能点击播放读音。
- 练习页去掉插图：只凭中文释义回忆拼写；资源包与统计页不受影响。
- 开机静默自启：开启开机自启后，登录 Windows 只在托盘运行、不弹出窗口；旧版写入的启动项在启动时自动更新。同一时间只运行一个词间，再次打开会显示已在运行的窗口。
- 学习日历按日期区分：过去的日期只显示已学习，未来的日期只显示待复习，今天两者都显示。
