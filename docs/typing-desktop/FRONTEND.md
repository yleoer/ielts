# 词间前端

页面源码位于 `typing-desktop/frontend`：`templates/` 的 index.html 与 stats.html 由 `typing-desktop/scripts/build_frontend.py` 渲染到 `typing-desktop/dist/`，编译时内嵌进桌面端。Vue 3 管理状态，Axios 请求 `location.origin + "/api"`，统计趋势使用 ECharts；三者来自 `typing-desktop/vendor/` 的固定版本，样式与图标为本地资源。请求经 `cijian://` 协议由 `typing-desktop/core/src/api.rs` 在本地处理，不访问远程服务。

## 练习

显示待复习与可学新词数量、每轮作答进度、插图、词性释义和输入框。正式练习首次请求 `/api/practice/queue?limit=3`，只展示第一道题，其余仅用于预加载插图。提交 `/api/practice/attempts?next_limit=3` 时，core 保存后重新选择队列，并通过响应顶层 `next_queue` 带回下一题及媒体预览，正常连续答题无需再串行 GET 队列。

中文提示使用 `chinese_senses`，按原顺序在输入框前显示首义项及前两条其他义项。首义项加大、加重，其他义项为 16px，全部居中；词性为 14px、Anki 同款赭红色 `#a4442d`，中文保留墨绿色 `#2d3e35`。长释义自然换行并保留字段内换行，不截断、不显示英文解释，使用 Vue 文本插值而非 `v-html`。

其余义项在输入框下方通过“展开其余 N 条含义 / 收起其他含义”显示或隐藏，不推动输入框。按钮至少 44px 高，提供 `aria-expanded` 与 `aria-controls`；鼠标点击后无滚动回焦输入，键盘、触摸、笔及辅助技术保留原生焦点。输入通过 `aria-describedby` 关联当前可见释义。换词、新一轮和刷新后默认收起，展开状态不写草稿。

正式、自由和错词重练共用此展示；完整义项随词条保存至草稿及错词数据，旧草稿缺少列表或列表为空时回退首义项，无需更改草稿版本。结果页错题摘要、统计页及同步历史继续使用 `chinese_meaning` 首义项。

提交后立即显示本地拼写反馈；错误或空输入 Space 看答案后可以在保存期间开始订正。统计计数和切题仍等待 core 确认，订正不重复提交。正确反馈的 180 毫秒与保存等待重叠。core 复核结果为准；失败或冲突保留待提交记录并提供恢复入口。支持 Enter、Esc、英文词组、连字符、撇号和 / 分隔答案变体。

返回的下一题仅在内存中最多复用 5 秒；停留过久、出现新到期词或手动同步后重新请求队列。刷新恢复草稿时重新取题，不持久化短期候选。预览不构成固定练习批次，不跳过新到期的学习／重学词。

不增加四档评分按钮、提交按钮、看答案按钮或输入占位提示。输入框通过 aria-label 保持可访问名称，插图替代文字不泄露词面；不加载音频。

## 插图预加载

提前请求当前及后续两道题的插图，并尝试异步解码。每个页面最多保留 32 个预加载引用；自由练习和错词重练按当前位置滚动预加载。缺图或解码失败不阻塞答题。

插图 URL 为 `/api/media/<note_id>/illustration?v=<版本>`。core 用 note id 找到词条的稳定 `SourceId`，再按用户导入的资源 ZIP 内的 `manifest.json` 读取文件，不依赖快照中的 `illustration_file`。音频同时提供 `audio_url`（优先英音，否则美音）及 `audio_urls`（存在时含 `uk/us/example/ielts`），对应 `/api/media/<note_id>/audio/<类型>?v=<版本>`。缺失插图返回空 URL，缺失音频不进入 `audio_urls`；缺失文件返回 404，ZIP 读取失败返回 503。所有媒体经过桌面自定义协议，读取无需访问凭证；当前练习页只预加载插图，音频接口供按需读取。详见 [独立媒体资源包](MEDIA.md)。

## 时间与草稿

- 页面时间默认按北京时间显示，不额外标注“北京时间”或时区名称。
- 使用 performance.now 记录有效作答时间；页面隐藏和同步弹窗暂停，恢复草稿只继续累计已记录的时间。
- 响应校准作答时间偏移，重试沿用原始 reviewed_at；保存耗时不计入评分。
- 草稿键为 typingPracticeDraftSession:fsrs:v1:<session_id>，保存词条、位置、反馈、计时和统计；sessionStorage 记住当前会话。
- 提交前将完整题目和答案另存为 typingPracticePending:fsrs:v1:<attempt_id>；确认且已保存确认后的草稿才移除。刷新或重新打开优先恢复待提交事件。
- 普通草稿有效期 7 天。待提交事件不会因过期自动丢弃；core 拒绝过期题目时显示原因和获取下一题入口。
- 保存失败时可自动或手动重试；存储失败时不发送新的正式提交。
- 旧 wordAtlas:v2 草稿退役，不回放旧会话统计。

## 完成与额外练习

正式练习不设每轮作答数或每日新词上限，每题后继续获取当前队列，直到队列为空。进度总数按已练题目加剩余可练词数动态显示，不再使用固定的 20；旧草稿中的 `sessionLimit` 也不再控制完成条件。结果页只声明已经确认保存的数量。待提交答案未处理时不能开始新一轮或退出。退出保留已保存成绩，不把未答题目记为 Again。

队列为空显示下次复习时间或当前无待复习与未开始单词，可检查待复习或自由练习。自由练习请求 `mode=free&limit=20`，从整个词池随机抽取最多 20 个不同词，不足时取全部，按实际返回数量显示进度；每题首次作答通过 `/api/practice/attempts` 保存到历史统计并更新 FSRS，包含未到期词。做完本轮后结束；冲突题目跳过后继续剩余词，不再抽取一批。页面标明自由练习计入记忆与统计，结果页显示已保存数量；仅错词重练与订正不重复计分。

自由练习沿用逐题草稿、待提交保存与重试机制。没有作答编号的旧自由练习草稿重新开始一轮，不补写旧作答。

## 同步

页首“同步 Anki”按钮打开同步弹窗，“立即同步”调用 `POST /api/sync/now`：拉取词库快照、上传未同步作答并合并其他设备的作答。服务器与可选资源包在首次启动的“首次设置”中配置，之后可从练习页或同步弹窗的“设置”修改。配置与后台同步周期见 [typing-desktop/README.md](../../typing-desktop/README.md)。

## 统计与验证

统计页首行按连续学习、已学习、已掌握、累计时长排列，随后是以当月居中的一年学习日历、学习近况、完整词库的 CEFR 等级进度和话题进度。绿色日历显示历史学习、浅灰显示未来待复习，有学习记录或待复习单词的日期可显示悬停提示并打开单词列表，空日期不显示悬停提示且不可打开弹窗；学习近况按含今天在内的最近 30 个北京时间自然日展示逐日作答量与正确率，副标题注明起止日期，横轴显示月/日。底部“参数优化记录”展开后显示自动评估进度、历史结果、验证指标和版本，支持分页查询与完整 JSON；详见 [统计页说明](statistics/FRONTEND.md)。

正式练习和自由练习的最终判分统一由 core 执行，不再计算错误分类；前端以相同答案规范提前反馈，并检查错词重练和订正。草稿只保存恢复练习所需的进度、计时、错词和作答 ID，不复制完整 FSRS 响应；完整复习历史保存在本地 SQLite，并通过同步服务器在设备间合并。

前端行为测试（仓库根目录）：

```powershell
node --test typing-desktop/frontend/src/app.test.cjs typing-desktop/frontend/src/stats.test.cjs
```

修改模板或静态资源后重新执行 `build_frontend.py` 并在真实窗口中检查输入、提交、订正、恢复、错误与窄屏布局；core 用 `cargo test` 验证。视觉约束见根目录 PRODUCT.md / DESIGN.md。

## 首次设置与资源导入

首次启动将服务器地址、访问令牌与可选的 ZIP 资源包导入放到同一“首次设置”窗口。以后可从练习页“设置”或同步窗口的“设置”重新打开；服务器由环境变量配置时只读，资源仍可导入。没有资源包也可先练习文字。

本地文件按 4 MiB 分块导入，显示复制与安装状态，失败后重新选择；页面跳转遗留的上传可取消。没有下载入口、下载接口或后台轮询；完成复制后读取 ZIP 清单并启用，不做逐文件 SHA 校验。缓存版本使用安装时的 UUID。

打开设置暂停练习计时，Tab 留在窗口内；允许关闭时，Esc/关闭返回触发按钮。安装只通过 `/api/resources/urls` 刷新媒体字段，保留 attempt_id、输入与作答状态；不重新出题。布局沿用现有组件和纸色墨绿，窄窗口滚动。详见 [独立媒体资源包](MEDIA.md)。
