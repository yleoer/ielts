# FSRS 选词与评分

桌面端正式练习通过本地路由 `GET /api/practice/queue?session_id=...&limit=1` 每次获取一道题，选词在 `typing-desktop/core/src/store.rs` 中执行。Anki 继续提供已学习的 Word Atlas 词池（来自同步服务器的词库快照），稳定标识为 `word-atlas:SourceId`；重新导入导致 `note_id` 改变时保留记忆。缺少或重复 SourceId 会报错。

服务器在快照中排除 `word_atlas::excluded` 标记的重复词，这些卡片在 Anki 也暂停。若被过滤项已学，服务器按其 canonical 标签让保留项获得练习资格；只继承资格，不合并两个 SourceId 的 FSRS 或作答日志。词头改写仍沿用原 SourceId，无需清空桌面数据库。详见 [词库修订与已有 Anki 更新](../../apkg-generator/data/word-atlas-revisions/README.md)。

## 顺序与数量

1. 已到期的学习和重学词。
2. 已到期的长期复习词。
3. 所有尚未开始的词，按 SourceId 稳定排序。

前两组按到期时间排序。每题保存后重新取队列，同一轮可再次练习刚到期的词。不会把未到期词填入正式队列。不设每轮作答数或每日新词上限，队列为空时完成。进度按已练题目与当前剩余可练词数动态显示。

`mode=free` 将当前全部词池打乱后抽取最多 20 个不同词，不足时全部返回；显式 `limit` 可以缩小批量，不能超过 20。包含未到期词，每题带作答编号与版本，首次作答逐题写入历史统计并更新 FSRS 与下次复习时间。core 根据已签发题目的模式允许自由练习提前复习，不接受客户端自行声明模式来绕过到期检查。仍检查时间顺序、题目有效期和并发版本。结果页错词重练与订正只用于即时巩固，不再次计分。

## 难点突破

`mode=difficult` 从当前 Anki 已学习词池中选取历史上答错过的不同词，包含尚未到期的词。沿用统计词库的易错排序：平滑错误率 `(答错次数 + 1) / (作答次数 + 2)` 降序，同分时按答错次数降序，再按英文词面（忽略大小写）及 SourceId 升序。次数来自所有设备合并后的 `word_reviews`，不按本轮错误筛选；以 SourceId 关联，Anki note_id 变化不丢失依据。

每轮默认最多 20 个，显式 `limit` 可缩小数量但不能超过 20，先对全部符合条件的词排序再截取。不足时返回实际数量，无答错记录时返回空列表，不用未答或全对词补齐；当前已移出词库或 Anki 尚未学习的词不参与。

此模式只读查询，返回词条及真实 `correct_attempts/total_attempts`，不签发 `attempt_id`，不创建或清理 `practice_items`。前端按既有答案规范提供本轮正误、订正与错词重练，不提交 `/api/practice/attempts`，不写作答日志、同步待上传记录或 FSRS 状态。因此不会改变统计、错误率、错误次数或下次复习时间，下一轮仍按原历史选词。草稿仅在本机保存本轮进度。

## 自动评分

| 首次独立作答 | 评分 |
| --- | --- |
| 错误或看答案 | Again |
| 正确且耗时 >20 秒 | Hard |
| 正确且耗时 <6 秒 | Easy |
| 正确且 6–20 秒，包含边界 | Good |

耗时为有效作答时间，页面隐藏和同步弹窗暂停计时，恢复草稿不累计离线时间。记录首次输入时间与答案长度用于后续分析。订正不重新计分。

## 调度

使用 `core/src/fsrs.rs` 移植的 py-fsrs 6.3.2 调度，默认保持率 0.9、学习步骤 1/10 分钟、重学步骤 10 分钟、开启间隔扰动。Easy 可跳过学习步骤进入长期复习。`State.Review` 且稳定性至少 21 天定义为已掌握，仍会继续到期复习。后台参数优化通过验证后自动启用，保留既有到期时间，卡片下次作答时根据历史应用新参数。

不再执行旧加权算法。统计或词库不可用时明确报错，不退回随机正式练习。

配置与参数优化见 [FSRS 实施说明](SRS-PLAN.md)。
