# 防御性代码审计

本仓库以“边界校验保留，内部重复兜底删除”为简化原则。判断一段代码是否应删除，不看它是否包含 `try`、`if` 或异常，而看它是否保护真实边界、定义现有契约，或者只是重复验证本仓库刚刚生成的状态。

## 已删除

- Word Atlas 生成脚本不再在每次打包后拆开 APKG，逐项重验 ZIP、SQLite、笔记、GUID、卡片、学习计划和媒体引用。生成过程与包级往返测试原先验证了同一结果；现在生产脚本只构建，结构验证由测试负责。
- 学习计划更新不再先后读取整张笔记表、卡片表和归档成员元数据进行自比对。实现只更新 `col` 元数据并原样复制其他归档成员，测试继续验证笔记、卡片和媒体没有变化。
- `AnkiReader.reopen()`、`get_learned_words()` 和 `get_word_by_id()` 没有生产调用方，删除接口及只为它们存在的测试断言。应用统一通过缓存词池读取。
- 配置和同步状态读取不再吞掉 `count_learned()` 的任意异常；`/api/words` 和统计概览也不再包一层重复的宽泛异常处理。存储异常交给 Flask 的统一错误处理，正常响应结构不变。
- Word Atlas 多义项解析只接受生成器固定输出的 `div` / `span` / `p` 结构，不再为任意嵌套、脚本、样式和所有 HTML 空元素维护通用状态机。词池生产调用方只读义项列表，因此缓存返回值不再深拷贝该嵌套列表。
- 多义项测试保留解析、接口、旧题、旧草稿和交互契约，删除对所有数量、练习模式、指针类型及列表变形的排列枚举。

### 桌面端与同步服务（2026-11）

- 前端：删除双语 `t()` 包装、网页版旧草稿兼容（缺义项列表回退、无作答编号的自由练习草稿、`wordAtlas:v2` 旧键）、草稿版本与结构自检、页面与 core 之间的时钟偏移估算、`online` 重试、`crypto.randomUUID` / `Image` / `echarts` 存在性检查、统计页 `localhost:8080` 回退地址和弹窗锁定 `body` 滚动（窗口本身不滚动）；三处重复的 `Esc` 处理合并到 `workspace.js`。
- core：评分不再重复校验耗时（提交入口已校验）；`Srs::new` 不再检查固定默认的保持率与阈值；参数优化删除同一进程内对报告的二次验证和多实例租约，启用前仍由 `Scheduler::new` 检查参数边界；词库快照不再序列化后重新解析；资源包不再重复打开 ZIP。
- 同步服务：`AnkiReader` 收敛为一次查询的缓存 `snapshot()`，删除未使用的词池、计数和媒体查询接口及旧版 `col.decks` 牌组读取（anki-sync-server 只产生新格式）；配置只读取 `backend/config/config.yaml`，非法数值启动即报错；删除无法触发的同步路径兜底。

### v0.4.0 分支复查

范围为 v0.3.0 之后的同步历史、托盘到期颜色、退出练习、难点突破和同步面板服务器配置。

- 服务器配置的 `GET /api/settings/server` 只读取桌面 core 的内存状态，不连接远端。页面首次需要时读取一次，保存后使用接口返回值更新；删除独立的读取失败重试界面和加载状态，以及只为首次打开面板的 `reloadServer` 参数。
- 服务器表单由“修改”入口或首次连接打开，不重复检查已加载、可编辑和正在编辑；输入框也不为不可能展示的只读表单维护禁用与占位文本。保存、同步中阻止重复操作和关闭的检查继续保留。
- 退出练习统一走同一函数，用一例验证退出保留已答记录、丢弃未答词、清理草稿并停止音频，不枚举所有模式。难点突破前端用一个短批次验证不提交和不补题，20 个上限由 core 测试验证；core 不再重复查询统计与上传队列来证明同一次选词未写入。
- 托盘测试分别验证到期时间边界和橙红色差，不重复组合到期词数、逾期和完成后的相同断言。同步测试删除自行构造重复服务器批次 ID 的故障注入（服务端主键已经保证唯一），保留未升级服务器的协议错误与旧数据替换验证。
- 同步服务的快照与新增历史使用同一事务，SourceId 保持唯一；后台定时检查失败后保留上次快照。这些直接保护个人学习记录，继续保留实现及事务失败回滚测试。旧本机历史迁移、离线缓存、已有答案不受同步影响、难点突破不写学习记录也继续保留覆盖。

## 继续保留

- HTTP 参数、登录跳转、媒体路径和 HTML 转义属于不可信输入边界。
- SQLite 事务、作答幂等、卡片版本冲突、时间顺序和 SourceId 校验保护统计与 FSRS 状态一致性。
- Anki WAL/只读打开兼容、同步前稳定性检查、临时文件替换和旧数据库迁移保护外部文件与既有数据。
- 已提交答案后的选题失败恢复、待提交记录与存储失败提示、统计明细筛选的请求竞态保护是文档化的用户行为，不作为冗余兜底删除。
- 桌面端优化器在启用候选参数前由 `Scheduler::new` 检查参数边界，fsrs-rs 训练的异常记录为失败而不启用。

测试保留真实输入边界、事务、迁移、并发和端到端行为。删除与已移除内部接口、运行时自校验器绑定的断言及重复排列枚举，不以减少用例数量为目标。
