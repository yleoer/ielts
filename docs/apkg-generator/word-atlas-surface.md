# Word Atlas 卡片设计约定

范围：`apkg-generator/templates/word-atlas/`；目标为 Anki 内的高频词汇复习。

## Direction contract

THESIS：仅生成英→汉卡，回忆面给词头与读音。话题和难度融入主体，不另设顶部栏或横线；其他义项直接展示。背面保留词义、插画、例句、搭配及用法提醒。

OWN-WORLD：延续源项目纸色与 Fraunces 字体，墨绿表达结构，赭红标识词性、读音与语境，例句译文折叠控件使用低强调的辅助灰绿色；原插画保持完整比例。

STORY：用户先看英文回忆中文词义，显示答案后先在英文语境中理解用法，再按需展开中文译文，并查看全部义项与搭配、播放英美或例句录音。

FIRST VIEWPORT：题面聚焦英文词头；答案上方左词义右插画，下方左例句右搭配。手机按断点改为单列。

FORM：源项目既有视觉系统延伸为离线词典卡片。seed: none (unavailable)。用户已确认含插画的完整版本。

FINISH：完整 APKG 通过数据库和媒体完整性验证，卡片设计与生成文档同步。

## 约束

- 完整牌组命名为 Word Atlas，全部词条放入一个牌组；保留话题和 CEFR 标签。
- 每词仅一张英→汉卡，按源词库顺序写入新卡位置，不生成汉→英卡。
- 模板使用 HTML/CSS 与 Anki 原生声音字段，不依赖前端框架、联网字体或 JavaScript。
- “在语境里记住”的中文译文逐条使用原生 `details` / `summary`，默认折叠并可点击展开；主词义和其他义项仍直接显示。
- 词族、近反义词和补充说明不在卡面显示；保留稳定字段用于兼容导入更新。
- 牌组和选项组名称均为 Word Atlas，牌组描述为空；授权保留在随包许可和项目文档。
- 07:00 先旧后新，17:00 与 23:00 处理实际到期卡；初学与遗忘重学均为单个 `10m` 步骤，每天新卡 20 张，音频按需播放。
- 复习阶段累计遗忘 8 次时标记为 leech 并暂停；检查释义范围、补充助记或语境后再恢复，不让难记卡片无限占用复习时间。
- 建议在客户端启用 FSRS，目标保留率从 0.90 起步并按个人历史优化；APKG 不覆盖 FSRS 开关、目标保留率或已优化参数。
