# Word Atlas 卡片设计约定

范围：`apkg-generator/templates/word-atlas/`；目标为 Anki 内的高频词汇复习。

## Direction contract

THESIS：英→中回忆面给词头与读音，中→英回忆面给中文释义、词性与插画。话题和难度融入主体，不另设顶部栏或横线；其他义项直接展示。背面保留词义、插画、例句、搭配及用法提醒。

OWN-WORLD：延续源项目纸色与 Fraunces 字体，墨绿表达结构，赭红标识词性、读音与语境；原插画保持完整比例。

STORY：用户先回忆词义或英文表达，显示答案后查看全部义项、语境与搭配，按需播放英美或例句录音。

FIRST VIEWPORT：题面聚焦提示词或中文题面；答案上方左词义右插画，下方左例句右搭配。手机按断点改为单列。

FORM：源项目既有视觉系统延伸为离线词典卡片。seed: none (unavailable)。用户已确认含插画的完整版本。

FINISH：完整 APKG 通过数据库和媒体完整性验证，卡片设计与生成文档同步。

## 约束

- 完整牌组命名为 Word Atlas，全部词条放入一个牌组；保留话题和 CEFR 标签。
- 每词英→中与中→英各一张，按源词库顺序写入新卡位置。
- 模板使用 HTML/CSS 与 Anki 原生声音字段，不依赖前端框架、联网字体或 JavaScript。
- 词族、近反义词和补充说明不在卡面显示；保留稳定字段用于兼容导入更新。
- 牌组和选项组名称均为 Word Atlas，牌组描述为空；授权保留在随包许可和项目文档。
- 07:00 先旧后新，17:00 与 23:00 继续当天学习卡；学习步骤 `1m 10h 6h` 按实际答题时刻计时，每天新卡 20 张，音频按需播放。
