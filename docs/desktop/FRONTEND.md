# 词间前端

页面源码位于 `desktop/frontend`：`templates/` 的 index.html 与 stats.html 由 `desktop/scripts/build_frontend.py` 渲染到 `desktop/dist/`，编译时内嵌进桌面端。Vue 3 管理状态，Axios 请求相对路径 `/api`（Linux 页面地址为 `cijian://localhost/`，Axios 会拒绝 `cijian:` 开头的绝对地址），统计趋势使用 ECharts；三者来自 `desktop/vendor/` 的固定版本，样式与图标为本地资源。请求经 `cijian://` 协议由 `desktop/core/src/api.rs` 在本地处理，不访问远程服务。协议处理（`desktop/app/src/main.rs`）给 `/api/` 响应加 `Cache-Control: no-store`，`/api/media/` 除外（URL 带资源包版本，可以放心缓存）：WebKitGTK 会把非 HTTP 协议的子资源视为永久有效，不加时 Linux 窗口重复读取同一接口（如复习汇总、同步状态）会拿到旧数据。

## 窗口布局与快捷键

两页共用 `templates/_header.html`：左侧边栏（品牌、练习／统计、底部同步、设置与折叠按钮）和 48px 标题栏（页面名、状态文字、窗口按钮）。窗口本身不滚动，只有 `.workspace-main` 内容区滚动。侧栏折叠状态保存在 `localStorage` 的 `cijian:sidebar`；窗口宽度不超过 960px 时 `sidebarRail` 始终为真，隐藏折叠按钮。弹窗遮罩覆盖整个窗口，窗口按钮的层级高于遮罩。标题栏状态文字由各页的 `titlebarNote` 计算属性提供。

`workspace.js` 的 `initDesktopShell()` 统一处理桌面习惯：`Ctrl+1` / `Ctrl+2` 切换页面，`Ctrl+B` 折叠侧栏，`Ctrl+,` 打开设置，`F5` / `Ctrl+R` 调用当前页的 `refreshPageData()` 重新读取本地数据，`Esc` 关闭设置、同步或统计明细弹窗；屏蔽打印、查找等浏览器快捷键和全部右键菜单。刷新快捷键不打开同步弹窗、不发起远程同步，也不重新加载整个页面；弹窗打开时忽略刷新。侧栏同步项显示 `/api/sync/status` 的 `last_sync_at`，启动、窗口重新可见和每分钟刷新一次，手动同步后立即更新。

练习页刷新重新请求正式练习队列及汇总，替换当前未作答题目并清空输入，保留本轮已保存的作答和统计；等待页或结果页按 F5 也会重新检查到期词，到期时直接开始练习。存在未保存的答案或正在显示已确认作答的反馈时，仅更新汇总，保留题目和订正状态；自由练习、难点突破、久未练习与错词重练也仅更新汇总，保留固定题目批次。统计页刷新概览、学习日历、学习近况、词库进度及已加载或加载失败的参数优化记录，复用已有图表容器。

## 练习

标题栏显示“待复习 X 个 · 新词 Y 个”（新词指全部未开始的词，不设每日上限；自由练习、难点突破、久未练习显示“最多 20 个”，错词重练注明“不计入记忆与统计”）；内容区显示每轮作答进度、词性释义和输入框，不显示插图，避免靠图片记词。进度条只在有当前题目或本轮已有作答时显示，作答前正确率显示“—”。正式练习每次只请求 `/api/practice/queue?limit=1`。提交 `/api/practice/attempts` 保存后，再请求一次队列，由 core 重新选择下一题；本机请求只需几毫秒，不随保存结果捎带下一题。

中文提示使用 `chinese_senses`，按原顺序在输入框前显示首义项及前两条其他义项。首义项加大、加重，其他义项为 16px，全部居中；词性为 14px、Anki 同款赭红色 `#a4442d`，中文保留墨绿色 `#2d3e35`。长释义自然换行并保留字段内换行，不截断、不显示英文解释，使用 Vue 文本插值而非 `v-html`。

其余义项在输入框下方通过“展开其余 N 条含义 / 收起其他含义”显示或隐藏，不推动输入框。按钮至少 32px 高，提供 `aria-expanded` 与 `aria-controls`；鼠标点击后无滚动回焦输入，键盘、触摸、笔及辅助技术保留原生焦点。输入通过 `aria-describedby` 关联当前可见释义。换词、新一轮和刷新后默认收起。

各练习模式共用此展示；完整义项随词条进入错词数据。结果页错题摘要、统计页及同步历史继续使用 `chinese_meaning` 首义项。

提交后等本机 core 保存完成（几毫秒），再按 core 的判分显示拼写反馈、计数，答对 180 毫秒后切题；保存期间输入框只读，不显示状态文字或占位块。正式练习切题时当前题留在原处、输入框只读，等 core 选出下一题后原地替换内容，输入框不移除重建、焦点不丢，也不闪现“正在加载单词…”；取题失败才换成错误与“重试”。释义区预留首义项加两条次要义项的高度并底部对齐，义项条数不同的两题之间输入框位置不变。订正不重复提交。保存失败或题目失效时在原位显示错误与“重试保存”／“获取下一题”，答案只保留在页面内存中，不写入 localStorage。支持 Enter、Esc、英文词组、连字符、撇号和 / 分隔答案变体。

答错或看答案后的订正区只显示反馈、正确拼写、可用音标和原错误输入，不展示例句或“下一题”按钮，减少订正时的干扰。订正正确后保留当前题目和输入，按 Enter 才切题；订正区空输入时也可按 Enter 继续。

不增加四档评分按钮、提交按钮、看答案按钮或输入占位提示。输入框通过 aria-label 保持可访问名称；不预加载音频，仅点击时读取。

输入框右侧的喇叭按钮（有本地读音时显示，保存和切题时禁用）播放当前词的读音。作答前点击即与空输入按 Space 一样提交空答案，评为“忘记”，错题回顾记作“(听读音)”；但不显示答案，已输入的内容保留，输入框继续可写，读屏提示“已计为忘记，请根据读音再拼一次”。此后 Enter 只在本地检查、不再提交：拼对按答对的方式 180 毫秒后切题；拼错或空输入（Enter 或 Space）显示答案并进入正常订正。之后再点喇叭只重播。中文释义只是文字，不能点击播放。

## 媒体

练习页不显示插图，也不预加载；资源包和 core 仍保留插图，URL 为 `/api/media/source/<SourceId>/illustration?v=<版本>`。core 使用词条的稳定 `SourceId`，再按用户导入的资源 ZIP 内的 `manifest.json` 读取文件，不依赖快照中的 `illustration_file`。音频同时提供 `audio_url`（优先英音，否则美音）及 `audio_urls`（存在时含 `uk/us`），对应 `/api/media/source/<SourceId>/audio/<类型>?v=<版本>`。缺失插图返回空 URL，缺失音频不进入 `audio_urls`；缺失文件返回 404，ZIP 读取失败返回 503。所有媒体经过桌面自定义协议，读取无需访问凭证；音频仅点击时读取。练习喇叭按钮、显示后的英文答案/错题回顾及统计单词明细可点击播放；`src/pronunciation.js` 供两页共用，按英音、结束后间隔 500 毫秒、美音的顺序播放，重复点击重新开始，切题/关闭明细/隐藏页面时停止。详见 [独立媒体资源包](MEDIA.md)。

## 时间与进度

- 页面时间默认按北京时间显示，不额外标注“北京时间”或时区名称。两页记录时间共用 `workspace.js` 的 `formatDateTime`：今天、明天、昨天显示为“今天 21:34”，其他日期为“11月20日 09:00”，跨年时带年份，不显示秒。
- 使用 performance.now 记录有效作答时间；页面隐藏、收进托盘和设置／同步弹窗打开时暂停。
- 重试保存沿用原始 reviewed_at 与耗时；保存耗时不计入评分。
- 不保存草稿或待提交答案。个人自用、一次只在一台电脑上练习，提交在本机完成；应用重启后正式练习直接继续下一道到期题，只丢弃本轮统计和自由练习、难点突破、久未练习、错词重练里未答完的题。

## 完成与额外练习

正式练习不设每轮作答数或每日新词上限，每题后继续获取当前队列，直到队列为空。进度总数按已练题目加剩余可练词数动态显示，不再使用固定的 20。结果页只声明已经确认保存的数量。有未保存的答案时不能开始新一轮或退出。退出保留已保存成绩，不把未答题目记为 Again；本轮没有已确认作答时（含第一题就退出、自由练习题目全部失效）不显示结果页，直接回到等待页。

结果页显示本轮指标和错题回顾，按钮只有“错词重练”（有错题时）和主按钮 `continuePlan`：汇总里有到期词或新词时为“开始复习／开始学习”并开始正式练习，否则为“完成”，调用 `returnToPlan()` 清空本轮状态回到等待页，不请求队列。进入结果页时 `revealResults()` 把内容区滚回顶部，并以 `preventScroll` 聚焦结果区域（`tabindex="-1"`，不显示焦点框），不聚焦底部主按钮，以免错题多时直接滚到最底，也避免空格误触按钮；在结果区域按 Enter 执行主按钮，空格、方向键和 PageDown 滚动内容。窗口收进托盘（`cijian-window-hidden`）时 `closeResults()` 同样回到等待页，再次打开不会停在旧结果上。

有当前词条时，进度条右侧显示“退出练习”按钮，输入框内 Esc 同效。退出不确认，显示“已退出练习”和本轮结果，停止读音与计时；保存或加载中禁用，保存失败时提示先重试或处理失效题目。

正式队列为空时进入等待页：不显示进度条，未到期时显示“暂无待复习”和“下次复习 今天 15:30（25 分钟后）”（`formatDueTime`，北京时间，今天／明天／M月D日，剩余时间按分钟向上取整）；词池为空时提示同步 Anki。等待页与结果页由 `schedulePlanCheck()` 维持一个定时器：在 `next_due` 之后 200 毫秒、且至少每 60 秒调用 `/api/memory/summary` 重读本机汇总，同时刷新倒计时；窗口恢复（`cijian-window-shown`、`visibilitychange`）时立即重读。后台同步带来的新词也由每分钟的重读发现。汇总出现到期词或新词时显示“复习时间到了”／“有新词可学”及主按钮“开始复习／开始学习”，按钮获得焦点但不自动开始。不再提供“检查待复习”按钮，F5 仍可手动刷新。有题目时不读取汇总。

自由练习请求 `mode=free&limit=20`，从整个词池随机抽取最多 20 个不同词，不足时取全部，按实际返回数量显示进度；每题首次作答通过 `/api/practice/attempts` 保存到历史统计并更新 FSRS，包含未到期词。做完本轮后结束；冲突题目跳过后继续剩余词，不再抽取一批。结果页显示已保存数量；仅错词重练与订正不重复计分。

自由练习同样逐题保存，失败时可原位重试。页面与 core 在同一台机器上，作答时间直接取本机时间，不估算时钟偏移。

等待页在“自由练习”旁提供“难点突破”（`mode=difficult`）和“久未练习”（`mode=stale`），结果页不提供这三个入口。各请求最多 20 个词，规则见 [选词说明](WORD-SELECTION.md#难点突破与久未练习)。本轮固定批次，不补词；无符合条件的词时显示说明和“返回”按钮，回到等待页。

这两种模式与自由练习相同：每题带作答编号，首次作答逐题保存，按同一规则评分并更新 FSRS、统计与同步日志，包含未到期词；结果页显示已保存数量，可订正和重练错词，完成后回到等待页。只有错词重练在本轮内判分、不提交作答，标题栏与完成页注明“不计入记忆与统计”。

## 同步

侧栏底部“同步”打开同步弹窗，“立即同步”调用 `POST /api/sync/now`：拉取词库快照、上传未同步作答并合并其他设备的作答。已配置时同步面板只展示服务器地址，点击“修改”才展开地址和令牌表单，使用“保存并同步”，不再跳转设置窗口。资源包、启动与窗口、软件更新统一在侧栏“设置”（`Ctrl+,`）中管理。配置与后台同步周期见 [desktop/README.md](../../desktop/README.md)。

后台同步合并到其他设备的作答时，桌面壳发出 `cijian-answers-merged` 事件（触发时机见 [设计说明](DESIGN.md)），两页都更新侧栏同步时间并调用 `afterSync()`；手动同步完成后也调用它。练习页若正显示尚未开始输入的正式题，就按 F5 的方式重新向 core 取题，在别的电脑已答过的词随之换掉；已开始输入、已显示判分、有未保存答案、结果页或固定批次的练习只更新汇总，旧题提交时由冲突提示跳过。统计页整页重读。收进托盘期间 `windowHidden` 保持为真，期间换题也不会开始计时，窗口恢复后才继续。

同步窗口展示服务器记录的最近 50 批新增已学词（按批次 ID 倒序，北京时间）。顶部“服务器同步”取 `last_anki_sync_at`，“最近一批新增”取最新批次数量；首次检查只建立基线，所以列表可能为空。“立即同步”只拉取服务器已有快照，不触发 Anki 检查；历史缓存在本机，离线可看。

## 统计与验证

统计页首行按连续学习、已学习、已掌握、累计时长排列，随后是以当月居中的一年学习日历、学习近况、完整词库的 CEFR 等级进度和话题进度。绿色日历显示历史学习、浅灰显示未来待复习，有学习记录或待复习单词的日期可显示悬停提示并打开单词列表，空日期不显示悬停提示且不可打开弹窗；学习近况按含今天在内的最近 30 个北京时间自然日展示逐日作答量与正确率，副标题注明起止日期，横轴显示月/日。底部“参数优化记录”展开后显示自动评估进度、全部历史结果、验证指标和版本；详见 [统计页说明](statistics/FRONTEND.md)。

正式练习、自由练习、难点突破和久未练习的最终判分统一由 core 执行，不再计算错误分类；前端用相同答案规范检查错词重练和订正。完整复习历史保存在本地 SQLite，并通过同步服务器在设备间合并。

测试分层、命令与真实窗口检查见 [桌面端测试](TESTING.md)。

修改模板或静态资源后运行真实窗口测试 `python3 desktop/e2e/run.py`（自动重新构建），默认、窄（侧栏图标栏）和矮窗口的布局另按 [桌面端测试](TESTING.md) 检查；core 用 `cargo test` 验证。视觉约束见根目录 PRODUCT.md / DESIGN.md。

## 服务器配置与资源设置

首次未配置服务器时自动打开同步面板，显示地址与令牌字段及“连接并同步”，配置成功前不能关闭。保存前调用 `/api/settings/server` 校验连接，失败留在原面板并保留输入；成功清空令牌输入，自动同步后加载练习，面板保持打开以查看结果。已配置时默认隐藏输入框，只展示保存的地址和“修改”入口。点击“修改”展开表单并聚焦地址；“取消”丢弃未保存的地址、令牌与错误提示，收起表单并返回“修改”按钮焦点。点击“保存并同步”更新服务器，令牌留空保留原值；校验失败保留展开状态及输入，成功后更新展示地址、自动收起且不重置已有练习。配置读取的是桌面 core 内存，本页首次需要时加载，保存后使用返回值更新；保存与同步期间禁止重复操作和关闭面板。浏览时“立即同步”固定在面板底部，编辑时只显示表单的保存与取消操作，窄窗口正文独立滚动。环境变量配置只展示地址，不显示“修改”或输入框，令牌始终不回显。

设置窗口独立管理“启动与窗口”“插图与音频”“软件更新”，打开时不请求服务器配置，也不再显示服务器字段或保存服务器的按钮。资源在设置中导入或更换，显示已安装数量与资源包版本（旧包显示“未标注版本”），没有资源包也可先练习文字。两个面板都暂停练习计时、约束 Tab 焦点，关闭后恢复触发按钮焦点；同步首次连接期间隐藏关闭入口，设置资源、更新或偏好保存时保留相应关闭保护。

本地文件按 4 MiB 分块导入，显示复制与安装状态，失败后重新选择；页面跳转遗留的上传可取消。没有下载入口、下载接口或后台轮询；完成复制后读取 ZIP 清单并启用，不做逐文件 SHA 校验。缓存版本使用安装时的 UUID。

打开设置暂停练习计时，Tab 留在窗口内；允许关闭时，Esc/关闭返回触发按钮。安装只通过 `/api/resources/urls` 刷新媒体字段，保留 attempt_id、输入与作答状态；不重新出题。布局沿用现有组件和纸色墨绿，窄窗口滚动。详见 [独立媒体资源包](MEDIA.md)。

常规设置首先提供“启动与窗口”分区，使用分段选择（两个单选按钮）切换“收进系统托盘”或“直接退出应用”，默认前者。通过 Tauri `get_close_to_tray` / `set_close_to_tray` 命令读取与即时保存，和服务器保存、联网校验独立，服务器由环境变量指定时仍可修改。读取或保存期间禁用两个选项；读取失败可重试，保存失败恢复原选项并提示重选，Tab 焦点范围包含这组选项。

同一区域的“开机自启动”开关（样式化的复选框）通过 `get_autostart` / `set_autostart` 命令操作当前用户 Windows 注册表启动项，默认关闭。启动项命令为带引号的程序路径加 `--autostart`，带此参数启动时主窗口创建后保持隐藏，只显示托盘图标，单击托盘或再次打开应用才显示；页面启动时照常取题，但读到窗口可见之前不计时，因此隐藏启动期间不计时。旧版本写入的不带参数的启动项，若指向当前程序，启动时自动补上参数，指向其他路径（如开发版）的不改动。每次打开设置重新读取系统实际启动项，不在 `desktop.json` 中复制状态；更改即时生效，仅限本机当前用户。加载／保存时禁用，读取失败提供独立重试，保存失败恢复原选项，保存过程中阻止关闭设置及重复提交；不依赖服务器连接，关闭行为的读取错误也不影响此开关。

`app/src/desktop.rs` 拦截主窗口原生关闭事件，统一覆盖标题栏关闭按钮及 Alt+F4；按偏好隐藏窗口或允许退出。原生隐藏／恢复事件通知前端：收进托盘时停止读音、暂停练习计时并关闭结果页，恢复时，正式练习的当前题若还没看过（未计时、未输入、未作答，例如开机静默启动时取的题），改为重新取题并刷新复习安排，避免几小时后打开仍是旧题、旧数字或已过期的题；看过或输入过的题保留，按原练习状态继续计时；空闲时重读复习安排；恢复和获得焦点时还会唤醒一次作答同步。托盘正常时沿用应用图标，到期前 10 分钟从上到下逐渐变为赭橙色（`#f6ad43`），到期或存在待复习词时整枚切换为砖红色（`#d84c3e`），作答完成后按下一次到期时间恢复；仅有新词不变色，不闪烁、不弹窗，窗口图标不变。单击恢复并聚焦，右键菜单提供“打开词间”和“退出”；显式退出及软件更新退出不受收进托盘设置影响。应用只允许运行一个实例（`tauri-plugin-single-instance`）：再次打开时新进程立即退出，并显示、聚焦已在运行的窗口（再次以 `--autostart` 启动时不显示），避免两个进程同时同步和写同一个数据库。托盘通过 `Store::summary()` 缓存复习安排，每 30 秒、鼠标移入及作答／同步后刷新，每秒按缓存推进颜色和提示，到期即转红，无需等待下次汇总读取或前端页面定时器：有到期词优先显示数量，否则按 `next_due` 显示剩余时间，没有复习安排时显示可学新词数量或暂无计划。读取失败恢复原图标并显示暂时无法读取，不显示旧倒计时。
