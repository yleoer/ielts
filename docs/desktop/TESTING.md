# 桌面端测试

词间是个人自用的桌面应用：上班在公司电脑、下班在家里电脑轮流使用，不会同时在两台电脑上练习。测试按这个场景覆盖业务规则和真实窗口，不为多端同时练习、多标签页或不稳定网络准备用例。删除实现时，同步删除只绑定该实现的断言；不以用例数量衡量覆盖。

## 分层

| 层 | 命令 | 覆盖 |
| --- | --- | --- |
| Rust core | 在 `desktop` 目录运行 `cargo test` | FSRS 与 py-fsrs 对照、出题与提交、两台设备的日志合并与重放、统计查询、媒体、参数优化 |
| Rust 桌面壳 | 同上（或 `cargo test -p cijian`） | 关闭偏好、托盘倒计时与颜色、自启动注册表项（Windows） |
| 前端逻辑 | 在仓库根目录运行 `node --test desktop/frontend/src/*.test.cjs` | 页面状态：结果页与等待页、到期检查、计时、保存失败重试、订正、错词重练、设置与同步面板、统计加载与明细、读音、软件更新 |
| 真实窗口 | 在 Linux 上运行 `python3 desktop/e2e/run.py` | 模板绑定、焦点与滚动、键盘操作、WebKitGTK 行为（如自定义协议的缓存）、原生关闭事件、真实 core 与后台同步 |
| 版本脚本 | `python3 -m unittest discover -s desktop/scripts -p test_version.py` | 标签与版本号格式、Cargo 工作区与锁文件同步 |

同步服务（`server/`）的测试与镜像检查见 [服务端测试](../server/TESTING.md)。

## 按改动选择

| 改动 | 执行 |
| --- | --- |
| 纯文档 | 核对内容、链接和命令 |
| `frontend/src/*.js` 的逻辑 | 对应的 `*.test.cjs`；接口契约也变时补 `cargo test` |
| 模板、样式、页面流程（焦点、键盘、结果页与等待页、统计页加载） | 前端测试 + 真实窗口 |
| `core/` | `cargo test`；只改一个模块可用 `cargo test -p cijian-core --test <文件名>` |
| 协议处理（`app/src/main.rs`）、Tauri 配置、`app/src/` | `cargo test -p cijian` + 真实窗口 |
| 同步协议（`core/src/sync.rs`、`remote.rs` 或服务端 `ledger.py`） | 两端测试 |
| 发布前 | 全部，并在 Windows 上按下文手工检查 |

同一轮改动完成后执行一次；失败修复、新增相关改动时再重跑。

## 真实窗口测试

```bash
sudo apt install xvfb webkitgtk-webdriver dbus
cargo install tauri-driver --locked
python3 desktop/e2e/run.py
```

只用 Python 标准库。脚本先构建页面和调试版应用，再启动以下环境，结束后全部清理：

- Xvfb 虚拟屏幕（自动选择空闲显示号），窗口不出现在桌面上，也不占用键鼠；
- 独立的 D-Bus 会话，测试应用的托盘图标不会出现在面板上；
- 内置的模拟同步服务器：开始时提供 5 个新词，中途加入 1 个新词，模拟 Anki 新学的词，并可替另一台电脑写入作答；
- tauri-driver（自动选择端口）和一次性的数据目录，不读写真实数据。

一次约 3 分钟，大部分时间在等两件事：答错的词 1 分钟后到期，以及每分钟一次的完整同步（加入新词、合并模拟的另一台电脑的作答）。退出码 0 表示全部通过，1 表示有检查失败，2 表示缺少依赖。截图保存在 `desktop/target/e2e/`，出错时另存 `failure.png`。tauri-driver 偶尔会复用已经关闭的连接，客户端遇到“连接被断开”时会重试一次。

检查的流程（`desktop/e2e/flows.py`）：

1. 练习一轮：作答前正确率显示“—”。5 个词全部答错并订正后进入结果页，作答几秒内已上传到服务器；结果页停在顶部，焦点在结果区域，空格只滚动不触发按钮；1 分钟后到期，“完成”变成“开始复习”。
2. 等待页：Enter 开始练习，Esc 零作答退出时不显示结果页；答完一轮后回到“暂无待复习”，没有进度条。
3. 统计页（`Ctrl+2`）：概览词数和时长、今天的日历格、学习近况图表、等级合计、当天单词明细、等级明细与答错记录高亮、参数优化记录。
4. 难点突破的作答已保存，久未练习的标题栏；后台同步加入新词后，等待页出现“开始学习”；新词显示在屏幕上时由另一台电脑答过，下一次同步后自动换掉并回到等待页；再打开统计页，数字随之更新（防止 WebKitGTK 缓存接口响应）。
5. 自由练习答一题后退出，结果页上点关闭按钮收进托盘，回到等待页。

真实窗口测试只覆盖 Linux 的 WebKitGTK。正式版运行在 Windows 的 WebView2 上，两者的差异需要按下文手工检查。

## 仍需手工检查

发布前在 Windows 上检查：

- WebView2 渲染与字体：练习页、订正、结果页、等待页、统计页，以及默认、窄（侧栏图标栏）和矮窗口；
- 托盘：单击恢复、右键“打开词间”和“退出”、到期前变橙、到期变红；
- 开机自启动：勾选后注册表启动项写入／删除、重新登录后启动；
- 软件更新：用上一版实际升级；
- 标题栏拖动、双击最大化、窗口缩放；
- 导入真实资源包后的插图与读音。

## 各测试文件

- `core/tests/golden.rs`：逐条比对 Rust 调度、评分与答案归一化结果。
- `core/tests/store.rs`：学习、重学、掌握，重试幂等，已复习词的旧题冲突，自由练习，队列顺序，北京时间新词计数，过期与非法时间，参数变更重放，路由路径与 JSON。
- `core/tests/difficult.rs`：难点突破的错误率排序、20 词上限与排除规则；久未练习按最后作答时间排序；两者签发题目，未到期也能保存作答并更新计划。
- `core/tests/media.rs`：按 SourceId 获取本地插图与英美读音、Anki note id 变化、缺失媒体、无哈希清单与资源包 URL 版本。
- `core/tests/media_install.rs`：资源包导入与替换、分块上传、取消与重试、安装记录损坏时仍可文字练习。
- `core/tests/stats.rs`：日历窗口与北京时间边界、到期分布、移出词库后的历史、近 30 天、连续天数、词库进度与平滑错误率排序、单词明细分页与参数校验、答错记录，并确认统计查询不写库。
- `core/tests/sync.rs`：两台设备经内存服务器同步（交错作答收敛为同一重放结果、重复同步不重传、只交换作答不下载词库、小分页、离线失败后补传、服务器词库替换本地、不同词库与时钟获取同一服务器历史、历史缓存、升级清空旧本机历史且保留作答、合并使未提交题目失效），以及首次设置（地址与令牌校验、错误令牌不保存、保存后同步、只改地址保留令牌、环境变量配置不可修改、损坏的 `server.json`）。
- `core/tests/optimize.rs`：有效复习计数、时间留出不泄漏、1000 条门槛、每月跳过、启用后保留到期时间并接受未提交题目、重启恢复、失败与异常一天后重试、无效结果、退出中断恢复、接口，另用 fsrs-rs 实际训练一次合成数据。`Cargo.toml` 在开发构建中为 `fsrs`、`ndarray` 开启优化，否则训练测试会慢很多。
- `app/src/desktop.rs`：关闭偏好默认值、保存后重启、写入失败保留原值，托盘倒计时、到期、仅有新词和空计划的提示。
- `app/src/tray_indicator.rs`：10 分钟边界、渐变进度、到期立即转红并保持、完成后恢复、无计划及无效时间；像素测试检查橙色与红色的色相差异、从上到下填充、透明度及白色书页。
- `frontend/src/app.test.cjs`：结果页与等待页（按钮、焦点、回到顶部、到期检查、收进托盘关闭结果页、零作答退出）、计时、保存失败重试、订正与错词重练、冲突跳过、各练习模式批次与保存、合并其他设备作答后替换未输入的题（不动已输入的题和结果页）、托盘隐藏期间换题不计时、插图预加载、多义项展示，以及与统计页共用的设置、资源导入、自启动和同步面板首次连接与修改。
- `frontend/src/stats.test.cjs`：整页加载与刷新、失败整页重试、日历与当天明细、学习近况图表、等级与话题明细分页与筛选竞态、答错记录与输入高亮、参数优化记录、时间格式与概览数字。
- `frontend/src/updates.test.cjs`：发现新版本、无更新、下载进度、失败重试、未保存答案阻止安装。
- `frontend/src/window-controls.test.cjs`：窗口按钮调用原生操作，最大化／还原图标与名称随窗口状态更新。
- `frontend/src/pronunciation.test.cjs`：英音、间隔 500 毫秒后美音，重复点击重新开始，缺失口音跳过。
- `scripts/test_version.py`：标签匹配、正式版格式与 Cargo 工作区／锁文件版本同步。
