# 词间前端

Flask/Jinja2 提供 index.html 与 stats.html；Vue 3 管理状态，Axios 调用同源 API，统计趋势使用 ECharts。样式与图标均来自本地资源，不需要前端构建服务。

## 练习

显示待复习与可学新词数量、每轮作答进度、插图、词性释义和输入框。正式练习首次请求 `/api/practice/queue?limit=3`，只展示第一道题，其余仅用于预加载插图。提交 `/api/practice/attempts?next_limit=3` 时，服务器保存后重新选择队列，并通过响应顶层 `next_queue` 带回下一题及媒体预览，正常连续答题无需再串行 GET 队列。

提交后立即显示本地拼写反馈；错误或空输入 Space 看答案后可以在保存期间开始订正。统计计数和切题仍等待服务端确认，订正不重复提交。正确反馈的 180 毫秒与网络等待重叠，不在服务器响应后再完整等待一次。服务端复核结果为准；失败或冲突保留待提交记录并提供恢复入口。支持 Enter、Esc、英文词组、连字符、撇号和 / 分隔答案变体。

服务器返回的下一题仅在内存中最多复用 5 秒；停留过久、出现新到期词或手动同步 Anki 后重新请求队列。刷新恢复草稿时重新取题，不持久化短期候选。预览不构成固定练习批次，不跳过新到期的学习／重学词。

不增加四档评分按钮、提交按钮、看答案按钮或输入占位提示。输入框通过 aria-label 保持可访问名称，插图替代文字不泄露词面；不加载音频。

## 插图预加载与缓存

提前请求当前及后续两道题的插图，并尝试异步解码。每个页面最多保留 32 个预加载引用；自由练习和错词重练按当前位置滚动预加载。缺图或解码失败不阻塞答题。

队列插图 URL 的 `v` 参数包含文件修改时间、大小和文件名，文件或引用变化后生成新 URL。版本匹配的图片使用 `private, max-age=31536000`，即使启用访问密码也可命中浏览器私有缓存，不需要逐题远程校验。图片入口仍检查访问凭证；未授权、未带版本或版本已过期的请求不获得长期缓存。其他业务响应保持原有缓存策略。

## 时间与草稿

- 使用 performance.now 记录有效作答时间；页面隐藏和同步弹窗暂停，恢复草稿只继续累计已记录的时间。
- 服务器响应校准作答时间偏移，重试沿用原始 reviewed_at；网络耗时不计入评分。
- 草稿键为 typingPracticeDraftSession:fsrs:v1:<session_id>，保存词条、位置、反馈、计时和统计；sessionStorage 记住当前标签页会话。
- 提交前将完整题目和答案另存为 typingPracticePending:fsrs:v1:<attempt_id>；服务器确认且已保存确认后的草稿才移除。刷新或重新打开优先恢复待提交事件。
- 普通草稿有效期 7 天。待提交事件不会因过期自动丢弃；后端拒绝过期题目时显示原因和获取下一题入口。
- 网络恢复时自动重试，也可手动重试；存储失败时不发送新的正式提交。
- 旧 wordAtlas:v2 草稿退役，不回放旧会话统计。

## 完成与额外练习

正式练习不设每轮作答数或每日新词上限，每题后继续获取当前队列，直到队列为空。进度总数按已练题目加剩余可练词数动态显示，不再使用固定的 20；旧草稿中的 `sessionLimit` 也不再控制完成条件。结果页只声明已经确认保存的数量。待提交答案未处理时不能开始新一轮或退出。退出保留已保存成绩，不把未答题目记为 Again。

队列为空显示下次复习时间或当前无待复习与未开始单词，可检查待复习或自由练习。自由练习请求 `mode=free&limit=20`，从整个词池随机抽取最多 20 个不同词，不足时取全部，按实际返回数量显示进度；每题首次作答通过 `/api/practice/attempts` 保存到历史统计并更新 FSRS，包含未到期词。做完本轮后结束；冲突题目跳过后继续剩余词，不再抽取一批。页面标明自由练习计入记忆与统计，结果页显示已保存数量；仅错词重练与订正不重复计分。

新版自由练习沿用逐题草稿、待提交保存与重试机制。旧版没有作答编号的自由练习草稿重新开始一轮，不补写旧作答；已有正式练习草稿及保存记录保留。

## 统计与验证

统计页首行按连续学习、已学习、已掌握、累计时长排列，随后是以当月居中的一年学习日历、本月学习、完整词库的 CEFR 等级进度和话题进度。绿色日历显示历史学习、浅灰显示未来待复习，所有日期均可打开单词列表；本月学习按自然月展示逐日作答量与正确率。底部“参数优化记录”展开后显示自动评估进度、历史结果、验证指标和版本，支持分页查询与完整 JSON；详见 [统计页说明](statistics/FRONTEND.md)。

正式练习和自由练习的最终判分统一由后端执行，不再计算错误分类；前端以相同答案规范提前反馈，并检查错词重练和订正。浏览器草稿只保存恢复练习所需的进度、计时、错词和作答 ID，不复制完整 FSRS 响应；完整复习历史由服务端持久化保存。
