# 词间前端

Flask/Jinja2 提供 index.html 与 stats.html；Vue 3 管理状态，Axios 调用同源 API，统计趋势使用 ECharts。样式与图标均来自本地资源，不需要前端构建服务。

## 练习

显示待复习与可学新词数量、每轮作答进度、插图、词性释义和输入框。正式练习每次从 /api/practice/queue 获取一道题，提交 /api/practice/attempts 后才推进。正确答案 180 毫秒后切题；错误或空输入 Space 看答案后进入订正，订正不重新提交。支持 Enter、Esc、英文词组、连字符、撇号和 / 分隔答案变体。

不增加四档评分按钮、提交按钮、看答案按钮或输入占位提示。输入框通过 aria-label 保持可访问名称，插图替代文字不泄露词面；不加载音频。

## 时间与草稿

- 使用 performance.now 记录有效作答时间；页面隐藏和同步弹窗暂停，恢复草稿只继续累计已记录的时间。
- 服务器响应校准作答时间偏移，重试沿用原始 reviewed_at；网络耗时不计入评分。
- 草稿键为 typingPracticeDraftSession:fsrs:v1:<session_id>，保存词条、位置、反馈、计时和统计；sessionStorage 记住当前标签页会话。
- 提交前将完整题目和答案另存为 typingPracticePending:fsrs:v1:<attempt_id>；服务器确认且已保存确认后的草稿才移除。刷新或重新打开优先恢复待提交事件。
- 普通草稿有效期 7 天。待提交事件不会因过期自动丢弃；后端拒绝过期题目时显示原因和获取下一题入口。
- 网络恢复时自动重试，也可手动重试；存储失败时不发送新的正式提交。
- 旧 wordAtlas:v2 草稿退役，不回放旧会话统计。

## 完成与额外练习

正式练习不设每轮作答数或每日新词上限，每题后继续获取当前队列，直到队列为空。进度总数按已练题目加剩余可练词数动态显示，不再使用固定的 20；旧草稿中的 `sessionLimit` 也不再控制完成条件。结果页只声明已经确认保存的数量。待提交答案未处理时不能开始新一轮或退出。退出保留已保存成绩，不把未答题目记为 Again。

队列为空显示下次复习时间或当前无待复习与未开始单词，可检查待复习或自由练习。自由练习请求 `mode=free&limit=20`，从整个词池随机抽取最多 20 个不同词，不足时取全部，按实际返回数量显示进度；每题首次作答通过 `/api/practice/attempts` 保存到历史统计并更新 FSRS，包含未到期词。做完本轮后结束；冲突题目跳过后继续剩余词，不再抽取一批。页面标明自由练习计入记忆与统计，结果页显示已保存数量；仅错词重练与订正不重复计分。

新版自由练习沿用逐题草稿、待提交保存与重试机制。旧版没有作答编号的自由练习草稿重新开始一轮，不补写旧作答；已有正式练习草稿及保存记录保留。

## 统计与验证

统计页展示正式作答数量、准确率、连续天数、有效时长、未来 7 天待复习、北京时间日历、30 天趋势、完整词库的 CEFR 等级进度和话题进度。点击有待复习词的日期可查看当天全部单词，零值日期禁用交互。底部“参数优化记录”展开后显示自动评估进度、历史结果、验证指标和版本，支持分页查询与完整 JSON；详见 [统计页说明](statistics/FRONTEND.md)。

正式练习和自由练习的判分统一由后端执行，不再计算错误分类，前端仅为错词重练和订正检查答案。浏览器草稿只保存恢复练习所需的进度、计时、错词和作答 ID，不复制完整 FSRS 响应；完整复习历史由服务端持久化保存。
