# 打字练习前端说明

这是 `typing-practice` 前端的知识库说明。

## 入口文件

- `typing-practice/frontend/templates/index.html`：练习页 Jinja2 模板
- `typing-practice/frontend/templates/stats.html`：统计页 Jinja2 模板

## 主要脚本

- `typing-practice/frontend/src/app.js`：练习流程、输入处理、判分、会话提交
- `typing-practice/frontend/src/stats.js`：图表数据加载和交互

## 运行依赖

前端通过 CDN 加载这些库：

- Vue 3
- Axios
- 统计页使用的 ECharts

页面由 Flask/Jinja2 渲染，没有独立前端构建步骤。全部样式来自本地 `frontend/assets/style.css`，不再加载 Tailwind CDN；字体使用系统字体。Vue 的 `{{ }}` 客户端绑定原样保留，Flask 将 Jinja2 变量分隔符设为 `[[ ]]`。

## 词间视觉与网页图标

- 使用 Impeccable 4.8.0 的 Operate 与 craft-floor 规范；产品约束和设计 token 分别记录在根目录 `PRODUCT.md`、`DESIGN.md`。
- 统一纸色、墨绿的中文界面与原色插画，网站名称为“词间”，品牌字使用系统衬线字体与轻字距。浏览器标签为“词间 · 练习”/“词间 · 统计”，密码页为“词间”。
- 移除黑白纯英文模式、外观切换按钮及相关滤镜，不再读取旧 `localStorage.stealthMode` 偏好；练习草稿和统计不受影响。
- `_header.html` 共用导航和线性图标；`_appearance.html` 共用 CSS、主题色和网页图标声明。所有图标来自本地 `icons.svg`，不使用表情或远程图标库。
- `favicon.svg` 是纸色底、墨绿双页与赭色书签标志的可编辑源文件，`favicon.ico` 提供 16/32/48/64px 后备尺寸，`app-icon.png` 为 180px 触屏图标；三者与顶栏标志一致，通过既有 `/assets/` 路由公开提供。图标版本参数用于刷新浏览器缓存。
- CSS 覆盖窄屏、长文本、键盘焦点、禁用、加载、错误、缺图与减少动态效果偏好。统计日历在窄屏横向滚动，页面本身不横向溢出。

## 练习页行为

- 页面不显示“IELTS 打字练习”“本轮练习”或“拼写练习”页首标题；错词重练时保留模式标识。
- 从 `/api/words` 获取练习单词。
- 卡片按顺序显示 200px 圆角插图、同一行的词性与中文含义，再显示输入框；图片的替代文字不泄露英文答案。
- 从 `illustration_url` 加载插图，不直接渲染 Anki 字段中的 HTML；图片加载失败时隐藏。
- 不提供音频播放控件，也不加载音频资源。旧草稿里的音频字段会在词条副本规范化时被丢弃，插图和练习进度继续保留。
- 只接受英文输入。
- 每题答案在前端本地校验，不再逐题请求后端。
- Enter 用于提交或进入下一题。
- 输入框不显示可见标签或占位提示，不提供提交按钮、看答案按钮、Enter 提交说明或底部快捷键提示。输入框通过隐藏的 `aria-label` 保持可访问名称。
- 空输入时，Space 用于跳过。
- Esc 用于退出练习。
- 答对后显示快速正确动画，并自动进入下一题。
- 普通练习完成后把会话统计提交到 `/api/stats/sessions`。

## 草稿会话

- 练习开始后会自动保存草稿。
- 草稿包含单词列表、当前题号、输入内容、答错展示状态、统计进度和练习模式。
- Word Atlas 正式版使用 `typingPracticeDraftSession:wordAtlas:v2` 存储草稿，保留媒体链接，不恢复缺少媒体字段的旧草稿或本地演示数据。
- 输入内容会节流保存，页面刷新后可以继续当前练习。
- 答对后的自动跳转期间，草稿会提前指向下一题，避免重复练同一个词。
- 完成练习、重新开始或重新拉取单词时会清理草稿。

## 错词重练

- 结果页会根据本轮错误和跳过记录生成错词重练入口。
- 错词重练直接复用本轮单词数据，不请求后端。
- 词条副本保留 `illustration_url`，错词重练也能显示图片。
- 错词重练会显示独立模式标识。
- 错词重练只用于当前巩固，不提交历史统计。

## 空状态和错误状态

- `/api/words` 返回空数组时展示“暂无可练习单词”。
- 后端返回错误或网络失败时展示错误状态和重试入口。
- 页面不会因为空数组停留在加载动画中。

## 统计页行为

- 从 `/api/stats/*` 加载概览数据和图表数据。
- 单词掌握度和错误类型图表支持点击查看明细。
- 掌握度和错误类型区块只显示数量，去掉两处“点击查看”文案。
- 桌面双栏共用顶部横线，两栏标题对齐；窄屏纵向排列时才在两个区块之间增加分隔线。报告区块相邻选择器仅作用于报告面板的直接子区块，避免误加到双栏内部。
- 窗口大小变化时图表会自适应。

## 开发说明

- 正式运行时，页面模板和静态文件由 Flask 同一个进程托管。
- 前后端按同一个镜像一起部署，不需要单独启动前端开发服务器。
- 直接打开页面只适合做静态查看；完整练习需要可用后端接口。
