# 统计页面

使用 Vue 3、Axios、ECharts 和本地 CSS；Flask 渲染 stats.html。沿用词间纸色、墨绿的中文界面。

顶部显示累计作答、正确率、连续天数和有效时长。随后依次是未来 7 天待复习、CEFR 等级进度、话题进度、学习日历和近 30 天趋势，底部保留参数优化记录。原“单词记忆”和“错误类型”模块已移除。

未来 7 天待复习以七列小柱图显示今天及后六天的单词数，前两列标注“今天”“明天”，其余使用月/日；零值也保留横线、数量和日期，窄屏仍显示完整七列。图表下方不展示规则说明文案。图表使用当前 FSRS 到期安排，今天包含逾期未复习和今天稍后到期的词，每个词只计一次；未开始和已移出练习池的词不计入。日期和分桶统一使用北京时间，作答后重新加载页面即可看到更新后的安排。

区块标题旁不显示“开始练习”链接。有待复习单词时，点击当天的柱、数量或日期，使用共用明细弹窗，显示该日期的全部单词、中文释义和北京时间到期时间，并按到期时间排序。窄屏将到期时间放在词条下方，避免挤断英文拼写。数量为零的日期保留显示但禁用交互，不打开弹窗、不请求明细；可用日期支持键盘聚焦并用 Enter/Space 打开，Esc 或关闭按钮退出。数据来自 `/api/memory/forecast-words?date=YYYY-MM-DD`，口径与柱状图一致；加载与失败状态独立显示，快速切换日期不会混入上一次请求的结果。如果打开后发现当天单词已被其他页面复习，则显示“这一天没有待复习的单词”。

等级进度从配置的 Word Atlas 牌组及子牌组读取全部有效词条，包含 Anki 尚未学习的词；按 SourceId 去重，不改变练习队列。六个圆环按 A1 入门、A2 基础、B1 进阶、B2 中高级、C1 高级、C2 熟练排列，以虚线连接；区块标题为“等级进度”，不显示“入门到熟练”和“起点”。圆环用赭黄表示学习中、墨绿表示已掌握、浅色表示未开始；两种进度均以该等级总词数为分母，不重复累计。等级下方和区块汇总均按“学习中 / 已掌握 / 总单词数”的顺序展示三个数字，如 `80 / 40 / 205`，不另列已掌握数量。已学是网站存在 FSRS 记录的词，已掌握沿用 Review 且 stability >= 21 天的标准，仍需到期复习。缺失或非法 CEFR 归入“未分级”，独立入口查看；零词数等级保留但禁用，无完整词库时显示同步提示。

话题按词库首次出现顺序展示，缺失 Topic 归入“未分类”。桌面两列、窄屏单列；每行显示话题名称、按“学习中 / 已掌握 / 总单词数”排列的三个数字，以及与圆环同色的分段进度；不再单独展示已学比例或已掌握数量。全部统计来自 `/api/stats/vocabulary-progress`，失败提供独立重试，不用零值替代失败。

点击等级或话题打开单词明细，支持“全部、未开始、学习中、已掌握”筛选，显示拼写、中文释义、CEFR、话题、记忆状态和下次复习时间（如有）。通过 `/api/stats/vocabulary-words` 每页读取 100 个词，显示已加载 / 筛选总数，并支持加载更多；翻页失败保留原列表和游标，重试不会重复添加。切换筛选重置分页并忽略过期响应。加载、空列表与失败分别显示。

等级、话题和待复习弹窗中，答过的词显示可点击的“答对 x / y”，x 为网站首次独立作答的正确次数，y 为总次数；未作答词仅显示纯文本 `0/0`，不提供展开入口，也不请求答错记录。正式与自由练习计入，幂等重试、订正和即时错词重练不重复计入。点击数字在原词条下展开答错记录，保持当前筛选、分页和列表位置，再次点击可收起。

答错记录通过 `/api/stats/word-errors?source_id=...` 以稳定 SourceId 查询，展开后不显示“答错记录”和次数标题，按最新到最早逐次将北京时间和当时输入放在同一行，不显示错误类型和正确答案；不按词面合并、不只显示最近一次。空输入显示“未输入”。输入按与当时答案最近的有效变体进行最小编辑对齐，忽略判分规则允许的大小写和空白差异，同时保留原输入的大小写、空白与标点。正确部分用正文色，错写字符用赭红色和下划线，多写字符用赭红色和删除线，漏写位置以赭色空心方框和点状下划线标记，不补出正确字母。字符附带悬停说明，避免仅依赖颜色。默认每页 50 条，可加载更早记录。初次加载、无答错记录和失败独立显示；翻页失败保留已有记录与游标，支持重试。展开后缓存本次弹窗内已读取的记录，切换词条不混用数据；后端返回最新答对/总次数同步更新数字。

弹窗支持键盘聚焦、Tab 焦点限制、Esc 关闭和关闭后返回触发按钮，打开时锁定背景滚动。窄屏词条时间换至下方，等级进度和日历可独立横向滚动，页面本身不溢出。

概览优先加载，其余模块独立请求 /api/stats/* 和 /api/memory/summary。北京时间用于日历边界和到期时间显示。没有单独的每日时长、速度或里程碑图表。

未来 7 天待复习始终保留标题；请求失败时显示错误与独立重试按钮，重试中显示加载状态，不用零值冒充加载失败。ECharts 实例通过 Vue.markRaw 排除深层响应式代理，窗口缩放时重新计算图表尺寸，手机端完整呈现 30 天趋势与正确率坐标轴。

底部“参数优化记录”默认折叠，展开后独立请求 `/api/memory/optimization` 与 `/api/memory/optimization/runs`，不阻塞其他统计模块。显示有效间隔记录门槛进度、后台状态、现用参数版本、保持率与下次评估时间；每次评估可展开查看训练/验证范围、记录数、原用/启用版本及默认、原用、候选的 Log loss / Brier 指标，并链接到完整 JSON。每页 10 条，支持刷新和加载更早记录。加载失败可重试，翻页失败保留已有记录与游标；没有历史时明确显示尚未评估。界面只提供查询，训练由服务端自动安排。
