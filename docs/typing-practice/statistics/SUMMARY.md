# 学习统计

正式练习与自由练习的首次作答均逐题保存，统计直接从 word_reviews 汇总，记忆状态来自 word_memory。自由练习每轮从整个词池随机抽取最多 20 个不同词，包含未到期词，更新历史统计与 FSRS；答错订正和结果页错词重练不重复计分。

当前页面首行显示连续学习、已学习、已掌握和累计时长，随后依次为学习日历、本月学习、CEFR 等级进度、话题进度与参数优化记录。学习日历显示前六个月、当月及后五个月，绿色表示已学习、浅灰表示当前待复习，有学习记录或待复习单词的日期可显示悬停提示并查看单词列表，空日期不显示悬停提示且不可打开弹窗；逾期待复习归今天。月度图按北京时间自然月展示，不再使用滚动 30 天，独立的七天待复习模块已移除。

单词明细统一按“易错优先”展示：已作答词按平滑错误率 `(答错次数 + 1) / (总次数 + 2)` 降序，同分时按答错次数降序、英文词面与 SourceId 升序，未作答词放最后；等级和话题先整体排序再分页，日历两组使用相同规则。

等级进度和话题进度统计完整牌组，以网站 FSRS 记录判断已学；已掌握对应 Review 且稳定性至少 21 天。练习和待复习仍使用 Anki 已学习词池。

旧统计在首次启用 FSRS 时清空一次；重复请求按 attempt_id 去重，不再整轮覆盖会话。已掌握（内部 mastered）以 FSRS 状态及稳定性判断，不再按累计答对次数判断。

统计页底部提供“参数优化记录”，查看后台自动训练进度、每月评估结果、验证误差和参数版本。首次达到 1,000 条有效间隔复习后自动尝试，验证改善才启用；记录与日志持续保留供回查。
