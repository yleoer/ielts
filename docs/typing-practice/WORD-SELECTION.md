# FSRS 选词与评分

正式练习通过 `GET /api/practice/queue?session_id=...&limit=1` 每次获取一道题。Anki 继续提供已学习的 Word Atlas 词池，稳定标识为 `word-atlas:SourceId`；重新导入导致 `note_id` 改变时保留记忆。缺少或重复 SourceId 会报错。

## 顺序与数量

1. 已到期的学习和重学词。
2. 已到期的长期复习词。
3. 所有尚未开始的词，按 SourceId 稳定排序。

前两组按到期时间排序。每题保存后重新取队列，同一轮可再次练习刚到期的词。不会把未到期词填入正式队列。不设每轮作答数或每日新词上限，队列为空时完成。进度按已练题目与当前剩余可练词数动态显示。

`mode=free` 将当前全部词池打乱后抽取最多 20 个不同词，不足时全部返回；显式 `limit` 可以缩小批量，不能超过 20。包含未到期词，每题带作答编号与版本，首次作答逐题写入历史统计并更新 FSRS 与下次复习时间。服务端根据已签发题目的模式允许自由练习提前复习，不接受客户端自行声明模式来绕过到期检查。仍检查时间顺序、题目有效期和并发版本。结果页错词重练与订正只用于即时巩固，不再次计分。

## 自动评分

| 首次独立作答 | 评分 |
| --- | --- |
| 错误或看答案 | Again |
| 正确且耗时 >20 秒 | Hard |
| 正确且耗时 <6 秒 | Easy |
| 正确且 6–20 秒，包含边界 | Good |

耗时为有效作答时间，页面隐藏和同步弹窗暂停计时，恢复草稿不累计离线时间。记录首次输入时间与答案长度用于后续分析。订正不重新计分。

## 调度

使用 `fsrs[optimizer]==6.3.2`，默认保持率 0.9、学习步骤 1/10 分钟、重学步骤 10 分钟、开启间隔扰动。Easy 可跳过学习步骤进入长期复习。`State.Review` 且稳定性至少 21 天定义为已掌握，仍会继续到期复习。后台参数优化通过验证后自动启用，保留既有到期时间，卡片下次正式复习时根据历史应用新参数。

`/api/words` 仅提供词库读取，不再执行旧加权算法。统计或词库不可用时明确报错，不退回随机正式练习。

配置与参数优化见 [FSRS 实施说明](SRS-PLAN.md)。
